01 / 项目定位

不是一个插件，
是一套服务端底座。

框架接管通用的生命周期与基础能力，让开发者把精力放在玩法、业务和管理工具上。它保留 Mindustry 多端构建能力，同时在 server 模块中提供完整的 YZF 扩展体系。

05 / 快速开始

准备 JDK 17，
让它跑起来。

Windows 使用 gradlew.bat，macOS / Linux 使用 ./gradlew。

进入完整规范 ↗
gradlew.bat server:run
gradlew.bat server:deploy
gradlew.bat tests:test
