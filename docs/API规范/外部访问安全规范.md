# 外部访问安全规范

## 适用范围

本规范适用于 YZF 框架的命令 socket、外发 HTTP/HTTPS 请求、远程 JSON 数据库请求，以及框架 WebSocket 连接。配置文件为 `config/yzf/config/external-access.hjson`。

默认策略是：公网连接必须认证，公网外发仅允许 HTTPS/WSS；内网连接默认可免 Token。

## Token 配置

Token 至少应为 128 个字符。可使用以下任一种来源，优先级为 `secretFile/keyFile`、`passwordFile`、`tokenFile`、`token`：

| 字段 | 类型 | 说明 |
|---|---|---|
| `token` | 字符串 | 直接 Token；仅适合临时测试。 |
| `tokenFile` | UTF-8 文本文件 | 文件内容作为 Token。 |
| `passwordFile` | UTF-8 文本文件 | 与 `tokenFile` 等价，适用于密码管理流程。 |
| `secretFile` / `keyFile` | 任意二进制文件 | 服务端对文件计算 SHA-512；客户端提交 `sha512:<base64url摘要>`。可使用图片等私有文件。 |

公开证书不是秘密，不能作为 `secretFile` 或 `keyFile`。私钥可以作为密钥素材，但应设置严格文件权限。

## 命令 socket

当远端地址满足认证条件时，客户端第一行必须是：

```text
AUTH <token>
```

认证成功后再发送常规控制台命令，每条命令一行。认证失败时服务端返回：

```text
ERR authentication required
```

## HTTP 与 WebSocket

框架发起的公网 HTTP/HTTPS、远程 JSON 数据库及 WS/WSS 连接会遵守以下策略：

- `requireTlsForPublic: true` 时，仅允许 `https://` 与 `wss://`。
- `requireTokenForPublic: true` 时，未配置有效 Token 将拒绝公网目标。
- `attachTokenToOutbound: true` 时自动附加 `Authorization: Bearer <token>`。

内网地址包括回环、站点本地和链路本地地址；是否要求它们认证由 `requireTokenForPrivate` 控制。

## TLS 证书边界

当前核心没有入站 HTTP/HTTPS 服务，因此没有可配置的证书、私钥或 mTLS 监听器。外发 HTTPS/WSS 使用 Java 的 TLS 证书校验。

若将来新增入站 HTTP API，应使用 Java KeyStore/PKCS#12 配置证书与私钥，并单独实现客户端证书校验；不要把公开证书当作 Token。
