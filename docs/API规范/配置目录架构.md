  缓存目录。
- `config/`

- `data/`
  运行数据目录。
- `local-json-database.txt`
  本地 JSON 存储说明文件。

  日志目录。

  模块目录。

  插件目录，本文档不展开。

## 核心配置

### `config/permissions.hjson`

用途：
权限、角色、玩家单独授权。

默认内容：

```hjson
default: []
defaultRoles: []
roles: {
  moderator: ["yzf.player.*"]
}
players: {}
```

字段说明：

- `default`
  默认权限列表。
- `defaultRoles`
  默认角色列表。
- `roles`
  角色与权限映射。
- `players`
  玩家单独权限映射。

### `config/player-storage.hjson`

用途：
玩家主存储总开关和主数据库选择器。

默认内容：

```hjson
{
  enabled: true
  serviceId: "player-sqlite"
  allowedTypes: ["sqlite", "mysql", "mariadb", "postgresql"]
  note: "Choose exactly one player storage database service and set enabled=true."
}
```

重要说明：

- 玩家主存储只能是以下四种之一：
  `SQLite`、`MySQL`、`MariaDB`、`PostgreSQL`
- `Redis`、`MinIO`、`Local JSON` 不是玩家主存储类型
- `serviceId` 必须指向 `config/services/` 中一个已经启用的服务

字段说明：

- `enabled`
  是否启用玩家主存储。
- `serviceId`
  当前玩家主存储对应的服务 ID。
- `allowedTypes`
  限制可选类型，只允许四种 SQL 类型。
- `note`
  备注说明。

### `config/security.hjson`

用途：
运行时安全和审计策略。

默认内容：

```hjson
allowProcessRuntimes: true
allowedRuntimes: ["js", "node", "java", "kt", "kts"]
auditEnabled: true
```

### `config/terminal.hjson`

用途：
终端增强配置。

默认内容：

```hjson
enabled: false
foundationSupport: true
pageSize: 15
fallbackOnDumbTerminal: true
```

## databases 目录

### `config/databases/comid-storage.hjson`

用途：
控制 comid 是否允许退回到旧版 JSON 文件存储。

默认内容：

```hjson
{
  allowLegacyFileFallback: false
}
```

说明：

- `false`
  不允许默认退回 `data/comid-registry.json`
- `true`
  当没有可用数据库后端时，允许退回旧版 JSON 文件

### `config/databases/local-json.hjson`

用途：
内置本地 JSON 数据库存储定义。

默认内容：

```hjson
{
  id: "local"
  name: "Local JSON Database"
  type: "local"
  enabled: false
  readOnly: false
  description: "Built-in pseudo-local JSON database. Disabled by default; set enabled=true to use it."
}
```

重要说明：

- 它是真正可写的本地 JSON 数据库，不是占位文件
- 默认不启用
- 可以被其他插件或脚本通过统一数据库桥调用
- 它不是玩家主存储四选一中的一种

实际落盘结构：

```text
databases/<dbId>/<category>/<key>.json
```

例如：

```text
databases/local/player/profile/12345.json
databases/local/system/comid/example.json
```

## services 目录

### 总说明

`config/services/` 中存放的是服务模板和实际数据库文件。

分成两类：

- 玩家主存储服务
  `sqlite` / `mysql` / `mariadb` / `postgresql`
- 附属可调用服务
  `redis` / `minio`

附属服务可以被插件、脚本、桥接层调用，但不会自动成为玩家主存储。

### `config/services/sqlite-default.hjson`

用途：
默认本地 SQLite 玩家主存储模板。

默认内容：

```hjson
{
  id: "player-sqlite"
  type: "sqlite"
  enabled: true
  databaseFile: "config/yzf/config/services/player-sqlite.db"
}
```

说明：

- 首次启动默认启用
- 默认优先作为本地玩家数据库
- 实际数据库文件是 `config/services/player-sqlite.db`

### `config/services/mysql-default.hjson`

用途：
MySQL 玩家主存储模板。

说明：

- 默认不启用
- 支持本机 MySQL
- 支持远程 MySQL

### `config/services/mariadb-default.hjson`

用途：
MariaDB 玩家主存储模板。

说明：

- 默认不启用
- 支持本机 MariaDB
- 支持远程 MariaDB

### `config/services/postgresql-default.hjson`

用途：
PostgreSQL 玩家主存储模板。

说明：

- 默认不启用
- 支持本机 PostgreSQL
- 支持远程 PostgreSQL

### `config/services/redis-default.hjson`

用途：
Redis 服务模板。

默认内容：

```hjson
{
  id: "service-redis"
  type: "redis"
  enabled: false
  clusterMode: "standalone"
  endpoint: "127.0.0.1:6379"
  username: ""
  password: ""
  namespace: "yzf"
  connectTimeoutMs: 10000
  readTimeoutMs: 15000
  nodes: []
  options: [
    "db=0"
    "masterName=mymaster"
  ]
}
```

说明：

- 默认不启用
- 支持本机 Redis
- 支持远程 Redis
- 支持 `standalone`、`cluster`、`sentinel`、`loadbalance`、`replication`
- 适合缓存、计数器、共享状态、插件桥接
- 它不是玩家主存储类型

### `config/services/minio-default.hjson`

用途：
MinIO 对象存储模板。

默认内容：

```hjson
{
  id: "service-minio"
  type: "minio"
  enabled: false
  clusterMode: "standalone"
  endpoint: "http://127.0.0.1:9000"
  bucket: "mindustry-yzf"
  accessKey: "minioadmin"
  secretKey: "minioadmin"
  region: "us-east-1"
  namespace: "yzf"
  connectTimeoutMs: 10000
  readTimeoutMs: 15000
}
```

说明：

- 默认不启用
- 支持本机 MinIO
- 支持远程 MinIO
- 也可用于 S3 兼容对象存储
- 适合截图、对象文件、附件和资源上传
- 它不是玩家主存储类型

## 如何启用数据库

### 默认本地 SQLite

默认已经启用。

需要保持：

- `config/services/sqlite-default.hjson` 中 `enabled: true`
- `config/player-storage.hjson` 中 `serviceId: "player-sqlite"`

### 改用 MySQL

步骤：

1. 打开 `config/services/mysql-default.hjson`
2. 把 `enabled` 改成 `true`
3. 修改 `endpoint`、`database`、`username`、`password`
4. 打开 `config/player-storage.hjson`
5. 把 `serviceId` 改成 `player-mysql`
6. 重启服务端

### 改用 MariaDB

步骤与 MySQL 相同，只是把目标文件换成 `mariadb-default.hjson`，并把 `serviceId` 改成 `player-mariadb`。

### 改用 PostgreSQL

步骤与 MySQL 类似，只是把目标文件换成 `postgresql-default.hjson`，并把 `serviceId` 改成 `player-postgresql`。

### 启用本地 JSON

打开：
`config/databases/local-json.hjson`

把：

```hjson
enabled: false
```

改成：

```hjson
enabled: true
```

说明：

- 启用后它会作为附属本地 JSON 数据库提供给插件和脚本使用
- 它不会替代玩家主存储

### 启用 Redis

打开：
`config/services/redis-default.hjson`

把 `enabled` 改成 `true`，再按实际情况填写：

- `endpoint`
- `password`
- `nodes`
- `clusterMode`

远程 Redis 直接填写远程地址即可。

### 启用 MinIO

打开：
`config/services/minio-default.hjson`

把 `enabled` 改成 `true`，再按实际情况填写：

- `endpoint`
- `bucket`
- `accessKey`
- `secretKey`

远程 MinIO 直接填写远程地址即可。

## 当前支持总结

### 玩家主存储支持

- `SQLite`
- `MySQL`
- `MariaDB`
- `PostgreSQL`

这四种只能选一种。

### 附属服务支持

- `Local JSON`
- `Remote JSON template`
- `Redis`
- `MinIO`

这些都可以被插件、脚本、桥接层调用，但不属于玩家主存储四选一。

### 远程支持情况

- `MySQL` 支持远程
- `MariaDB` 支持远程
- `PostgreSQL` 支持远程
- `Redis` 支持远程
- `MinIO` 支持远程
- `Local JSON` 是本地文件型，不是远程服务

## 配置修改后如何生效

步骤：

1. 修改对应 `.hjson` 文件
2. 保存文件
3. 重启 `server-release.jar`

说明：

- 首次启动会自动释放默认模板
- 如果文件已经存在，后续启动不会覆盖你的手动修改
